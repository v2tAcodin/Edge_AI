## Agent skills

Issues and specs are tracked on GitHub Issues for https://github.com/v2tAcodin/Edge_AI using `gh` CLI. See `docs/agents/issue-tracker.md`.

Canonical triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.
